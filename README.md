# Zelta BTC Strategy

### Quantitative Research | Algorithmic Trading | Backtesting

Zelta BTC Strategy is a quantitative trading research project focused on
developing, backtesting, and evaluating systematic trading strategies for
the BTC/USDT market.

## Research Objectives

- Develop systematic trading strategies using historical market data.
- Evaluate strategy performance through historical backtesting.
- Explore adaptive trading approaches across different market regimes.
- Examine transaction costs, execution assumptions, and risk management.

## Strategy Architecture

The project currently contains four core Python modules:

| Module | Purpose |
|---|---|
| `run_backtest.py` | Backtesting execution and analysis |
| `strategy.py` | Core trading strategy |
| `strategy_adaptive.py` | Adaptive strategy implementation |
| `zelta_engine.py` | Trading engine and supporting logic |

## Research Methodology

The research workflow focuses on:

1. Historical market data processing.
2. Systematic trading signal generation.
3. Backtesting under defined execution assumptions.
4. Performance and risk evaluation.
5. Comparison of alternative strategy implementations.

## Performance Evaluation

The strategy will be evaluated using quantitative performance metrics,
including returns, risk-adjusted performance, and drawdown analysis.

Performance figures will be documented alongside the assumptions and
limitations of the backtesting framework.

## Limitations

Historical backtest results do not guarantee future performance.
Results depend on the assumptions used for execution, transaction costs,
and risk management.

## Disclaimer

This project is intended for educational and quantitative research purposes.
It is not financial advice or a recommendation to trade any asset.
